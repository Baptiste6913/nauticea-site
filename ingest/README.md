# Dépôt des fiches PDF

Déposez ici la fiche PDF générée depuis BoatWizard, telle quelle, sans la
renommer ni la retoucher. Le dépôt d'un fichier `.pdf` dans ce dossier
déclenche l'ingestion, qui ouvre une demande de fusion à relire.

Mode d'emploi complet, y compris depuis un téléphone : `docs/PUBLIER-BATEAU.md`.

Une fiche traitée est déplacée dans `archive/` par le workflow : ce dossier
ne garde donc que les fiches en attente.
